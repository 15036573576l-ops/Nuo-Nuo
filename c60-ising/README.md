# C60 反铁磁伊辛模型：h = J 时的基态简并度

## 题目

> Classical antiferromagnetic Ising model on the C60 buckyball graph (60 vertices, 90 edges):
> H = J Σ_{edges} s_i s_j − h Σ_i s_i, with s_i = ±1 and J > 0. How many ground states are there at h = J?

中文：C60 足球烯图上的经典反铁磁伊辛模型，磁场 h 正好等于 J 时，有多少个基态？

## 答案

**3473405**

## 结构

设 D 是朝下的自旋集合，e(D) 是 D 内部的边数。h = J 时

E/J = 30 − 4(|D| − e(D))，

所以基态就是让 |D| − e(D) 最大的 D，最大值是 24（等于 C60 的独立数）。

各磁化扇区的最低键能 B(M) = Σ s_i s_j：

| M | B(M) | 构型数 |
|---|---|---|
| 0 | −66 | 16000 |
| 2 | −64 | 144000 |
| 4 | −62 | 530040 |
| 6 | −60 | 1015440 |
| 8 | −58 | 1063950 |
| 10 | −56 | 577260 |
| 12 | −54 | 126715 |
| 14 | −48 | 3085020 |

M 从 0 到 12，B(M) 正好落在一条斜率为 1 的直线上，所以 h = J 时这 7 个扇区的能量完全相同（都是 −66J），全部算基态：

16000 + 144000 + 530040 + 1015440 + 1063950 + 577260 + 126715 = 3473405。

磁化曲线：0 < h < J 时 M = 0（16000 个基态），J < h < 3J 时 M = 12（126715 个，即 C60 的最大独立集），h > 3J 时饱和。

## 陷阱

| 想法 | 结果 |
|---|---|
| 只算相邻两个平台 M = 0 和 M = 12 | 16000 + 126715 = 142715 |
| 以为 h = J 还在零场平台里 | 16000 |
| 以为已经进入 M = 12 平台 | 126715 |

中间 5 个扇区也落在同一条直线上，是这道题最容易漏的地方。

## 验证

- `c60.py`：从正二十面体截角构造 C60 图，检查 60 点、90 边、3 正则、平面、围长 5、12 个五边形、20 个六边形、自同构群阶 120。
- `dos.py`：前沿转移矩阵，精确计算联合态密度 g(B, M)，覆盖全部 2^60 个构型。两种不同的消元顺序结果逐项相同。
- `test_small.py`：同一套 DP 在十二面体、Petersen 图、截角四面体、Desargues 图上和 2^n 暴力枚举逐项一致。
- `analyze.py`：读态密度，求各扇区最低能量、平台和能级交叉。
- `verify.py`：换一种约化（只跟踪 |D| − e(D)）、另写一套位掩码 DP、换两种顺序，独立数出 3473405；再用补图最大团枚举，单独数出最大独立集 126715 个。
- 零场简并度 16000 和解析结果一致：二十面体完美匹配数 125 × 每对 2 种六边形选择 2^6 × 全局翻转 2。

运行：`pip install numpy networkx`，然后 `python3 dos.py 0 && python3 analyze.py && python3 verify.py`（总共约 1 分钟）。
