# 1000 枚硬币、4 枚假币、称两次

题目：1000 枚硬币里有 4 枚假币，假币更轻且重量相同。天平只能用两次，最多能保证认出多少枚真币？

答案：143 = ⌈1000/7⌉

- 第一次：286 对 286，剩下 428 枚不上秤。
- 不平衡：较重的那一盘里至多 1 枚假币。从中取 95 对 95 再称，能认出至少 190 枚。
- 平衡：左盘放剩下的 428 枚，加上右盘中的 1 枚。右盘放左盘的 286 枚，加上右盘中的 143 枚。三种结果都能认出至少 143 枚。

文件：

- `coin.c`：两盘数量相等时的穷举搜索，输出小 N 的最优值。
- `chk.c`：在 N = 1000 上检查上面的构造。
- `gen.c`：允许两盘数量不等，并考虑假币重量未知的一致性。已验证 N = 7..13。
- `coin.py`：Python 版的辅助检查。

编译：`gcc -O2 coin.c -o coin`

说明：下界（能认出 143 枚）已验证。上界（不可能超过 143 枚）只有小 N 穷举的数值证据，没有严格证明。
