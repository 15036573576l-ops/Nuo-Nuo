# 进位对偶猜想（糯糯猜想）

## 题目卡（英文原文，测模型时直接用）

**卡 A（终极版，带误差项）**

> For a prime p and a nonzero integer m, let ν_p(m) denote the exponent of p in m.
> Prove that for every pair of distinct primes p, q and every ε > 0,
>
>   ν_p( C(2qⁿ, qⁿ) ) · ν_q( C(2pⁿ, pⁿ) ) = n²/4 + O_{p,q,ε}( n^{3/2+ε} )   as n → ∞,
>
> where C(a, b) is the binomial coefficient. In particular the left side divided by n² tends to 1/4.

**卡 B（伪装版，只要极限）**

> Let ν_p(m) denote the exponent of the prime p in the integer m. Prove that for any two distinct primes p and q,
>
>   lim_{n→∞} (1/n²) · ν_p( C(2qⁿ, qⁿ) ) · ν_q( C(2pⁿ, pⁿ) ) = 1/4.

卡 B 更像一道竞赛题，诱饵更足。卡 A 难度更高。两张卡都没有现成证明。

## 中文陈述

对任意两个不同的素数 p、q：

ν_p(C(2qⁿ, qⁿ)) · ν_q(C(2pⁿ, pⁿ)) = n²/4 + O(n^{3/2+ε})

**结论：极限是 1/4，和 p、q 无关；误差指数 3/2 是“平方根消去”的量级，类似黎曼猜想里的 x^{1/2+ε}。**

这是一个开放猜想，不是有答案的题。它的真假目前无法证明，下面的数值只是证据。

## 为什么它看起来能做（诱饵）

1. 中心二项式系数加 p-进赋值，第一反应就是 Kummer 定理，一步就能化成“进位次数”，让人觉得有进展。
2. 常数 1/4 和 p、q 无关，而且 log_p q · log_q p = 1 正好约掉，很像背后藏着一个“对偶”或双射。
3. 用“数字是随机的”去算，每一位的进位概率恰好是 1/2（任何进制都是），乘起来就是 1/4，很容易写出一份看起来完整的“证明”。

## 解剖：为什么做不动

**第一步（可证）。** 由 Kummer 定理，ν_p(C(2m, m)) 等于 m + m 在 p 进制下的进位次数。p = 2 时就是 m 的二进制 1 的个数：

- ν_2(C(2·3ⁿ, 3ⁿ)) = s_2(3ⁿ)，即 3ⁿ 的二进制数字和
- ν_3(C(2ⁿ⁺¹, 2ⁿ)) = 2ⁿ 自加时的三进制进位数

**第二步（可证，平凡界）。** 进位数不超过位数，所以乘积 ≤ (n·log_p q + 1)(n·log_q p + 1) = n² + O(n)。也就是 0 ≤ liminf ≤ limsup ≤ 1。据我查到的文献，limsup 这一侧也没有比 1 更好的已知上界。

**第三步（启发式，非证明）。** iid 均匀数字下，进位是一个两状态马尔可夫链，平稳分布下每位进位概率恰为 1/2（`carry_chain.py` 对 b = 2..199 用有理数精确验证）。于是两个因子分别约为 (n·log_p q)/2 和 (n·log_q p)/2，乘积约为 n²/4。

**第四步（卡住）。** 取 p = 2、q = 3：

- 乘积为 0 当且仅当 2ⁿ 的三进制只含 0 和 1。n = 2（4 = 11₃）和 n = 8（256 = 100111₃）时乘积确实为 0。
- **所以“n 充分大时乘积 > 0”就等价于 Erdős 1979 年的三进制猜想**（2ⁿ 的三进制在 n > 8 时一定含有数字 2）。这个猜想至今没有解决，Erdős 本人说过“看不到任何方法”。
- 猜想成立 ⇒ ν_3(C(2ⁿ⁺¹, 2ⁿ)) ≥ (1/4 − ε)n² / (1.59n + 1)，所以 Erdős 猜想成立（至多有限个例外）。
- 猜想成立 ⇒ s_2(3ⁿ) ≥ (1/4 − ε)n² / (0.631n + 1) ≈ 0.396n，**是线性下界**。目前最好的结果是 Stewart（1980）的 log n / log log n 量级。
- 极限等于 1/4 还要求 3ⁿ 的二进制、2ⁿ 的三进制的数字（以及数字块）频率都正常。这比 Dupuy–Weirich（2016）提出的数字频率猜想还要强，那个猜想本身也是开放的。
- 卡 A 的 n^{3/2+ε} 误差项是中心极限定理量级的涨落控制，比“数字正规”还要强一级。

**难度阶梯：**

| 层级 | 内容 | 状态 |
|---|---|---|
| 0 | Kummer 化简、平凡上界、启发式 1/4 | 可证或可算 |
| 1 | (2,3) 情形 n 充分大时乘积 > 0 | **等价于 Erdős 三进制猜想，开放** |
| 2 | liminf 乘积/n² > 0 | 推出 s_2(3ⁿ) 有线性下界，远超 Stewart |
| 3 | 极限 = 1/4 | 强于 Dupuy–Weirich 数字频率猜想 |
| 4 | 误差 O(n^{3/2+ε}) | 涨落层面，比正规性更强 |

能做到的只有第 0 层，估计完成度不到 8%。第 1 层已经卡了 47 年。

## 现有工具为什么不够

| 工具 | 能做什么 | 为什么不够 |
|---|---|---|
| Baker 对数线性型（Stewart 1980） | 非零数字个数 ≫ log n / log log n | 只有对数量级，离线性差太远 |
| S-单位方程、子空间定理（Dimitrov–Howe） | 处理非零数字个数有界的情况 | 数字个数一旦随 n 增长就失效 |
| p-进动力学（Dupuy–Weirich 2016；Li–Zhao 2026） | 最低若干位数字对 n 做 Cesàro 平均后均匀分布 | 只管低位，而且是对 n 平均，不是每个 n |
| Weyl 均匀分布（n·log₂3 mod 1） | 控制最高若干位 | 只管高位 |
| Mauduit–Rivat 型 Fourier 方法 | 素数、平方数的数字和 | 只适用多项式型序列，不适用另一进制下的指数序列 |
| Furstenberg ×2×3、Rudolph 测度刚性 | 不变测度分类 | 需要正熵等假设，管不到单条轨道 |

一句话：**两头的 O(log n) 位能看清，中间 Θ(n) 位完全看不见，而猜想的全部内容都在中间。**

## 弱模型常见的假证明

| 错误做法 | 错在哪 |
|---|---|
| “3 模 2^k 的阶是 2^{k−2}，所以数字均匀分布” | 只管最低 O(log n) 位，而且是对 n 平均 |
| “n·log₂3 mod 1 均匀分布（Weyl），所以数字均匀” | 只决定最高几位 |
| 大数定律、中心极限定理直接套在 3ⁿ 的数字上 | 确定性数字不是随机变量，这一步正是要证的东西 |
| 构造 qⁿ 的 p 进制进位和 pⁿ 的 q 进制进位之间的“对偶双射” | log 相消只是两个长度的乘积约等于 n²，背后没有结构 |
| 引用 Furstenberg ×2×3 定理得到“独立性” | 定理说的是不变测度，不是单条轨道 |
| 对 n 归纳 | 数字和不单调，n → n+1 时没有可控的递推 |

“涨落”指 (乘积 − n²/4) / n^{3/2}，在 n ≥ 100 上统计。随机模型把数字换成同样长度的 iid 均匀随机数字，n = 8000，抽样 4000 次。真实数据和随机模型的涨落几乎一样，均值都接近 0，最大偏差约 2。这支持 1/4 的极限，也支持 n^{3/2} 的误差指数（指数不能再小，因为涨落本身就是这个量级）。

## 文件

- `kummer_check.py`：直接算二项式系数的赋值，和进位数对账；列出 n < 2000 内 (2,3) 的零点（只有 0、2、8）。
- `carry_chain.py`：进位马尔可夫链的平稳进位概率，有理数精确计算加随机抽查。
- `scan.c`：逐个 n 维护 qⁿ 的 p 进制和 pⁿ 的 q 进制数字，计算两个因子、比值和归一化偏差。
- `random_model.c`：随机数字模型的偏差分布。
- `run_all.sh`：一键复现，输出见 `results.txt`。

编译：`gcc -O2 -o scan scan.c -lm`，用法：`./scan 2 3 40000 1000`

## 诚实说明

- 严格成立的只有：Kummer 化简、平凡上界、“猜想 ⇒ Erdős 三进制猜想（有限例外形式）”、“猜想 ⇒ s_2(3ⁿ) 线性下界”这几条推导。
- 1/4 和 n^{3/2} 只有启发式和数值证据，猜想本身可能是错的，但目前没有任何反面迹象。
- 这道题的核心属于 Erdős、Stewart、Dupuy–Weirich 这一族“不同进制下的指数序列”问题。它不是一个全新的现象，而是把这族问题换了外衣，再加强到“乘积极限 + 平方根误差”的形式。难度的保证正来自这里：证明它至少要先解决 Erdős 猜想。
- 按我搜到的范围，没有找到这个乘积形式的现成表述。
